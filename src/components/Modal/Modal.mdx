# Modal

A dialog that blocks the page to get a decision. Includes a Confirm order variant.

<Canvas of={Stories.ConfirmOrder} />

## When to use
<ul><li>Decisions that must be made before continuing, such as confirming an order.</li></ul>
## When not to use
<ul><li>Non-blocking information (use a Toast).</li><li>Long forms (use a page).</li></ul>

## Usage
```tsx
<ConfirmOrderModal open={open} onClose={close} onConfirm={place} lines={lines} />
```

## Screen reader notes
Announced as "Confirm your order, dialog" followed by its description. Native dialog with showModal() makes the rest of the page inert. Focus moves to Back to basket (the safe action) and returns to the trigger on close.

## Known limitations
<ul><li>Focus return and scroll lock are implemented in React; they are verified in jsdom tests with a showModal polyfill, not in a real browser by an automated test.</li><li>Backdrop click closes the dialog; this may be undesirable for destructive confirmations.</li></ul>
