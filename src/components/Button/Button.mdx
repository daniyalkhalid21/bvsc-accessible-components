# Button

A native button for actions: add to basket, place order, remove an item. Variants: primary, secondary, danger. Supports a loading state and icon-only use.

<Canvas of={Stories.Primary} />

## When to use
<ul><li>Triggering an action on the current page (not navigation).</li><li>Icon-only buttons, but always with an accessible name.</li></ul>
## When not to use
<ul><li>Navigating to another page. Use a link.</li><li>Do not put the only explanation of a disabled state in the button; say why elsewhere.</li></ul>

## Usage
```tsx
<Button variant="danger" onClick={remove}>Remove item</Button>
<Button loading loadingText="Placing order">Place order</Button>
<Button iconOnly aria-label="Open basket"><BasketIcon /></Button>
```

## Screen reader notes
Announced as "name, button". Loading adds ", loading text" to the name and sets aria-busy. Disabled buttons are announced as "dimmed/unavailable" by most readers.

## Known limitations
<ul><li>Loading keeps the button focusable via aria-disabled-like behaviour (clicks ignored), so screen reader users can still find it.</li><li>Disabled text contrast (4.15:1) is exempt from WCAG 1.4.3 but is low; do not rely on disabled state to convey required information.</li></ul>
