# Tabs

Switch between related views of one product: Description, Dosage, Storage.

<Canvas of={Stories.Default} />

## When to use
<ul><li>Peer sections of content where only one is shown at a time.</li></ul>
## When not to use
<ul><li>Steps in a process (use a stepper).</li><li>More than about 6 tabs.</li></ul>

## Keyboard interaction
<table><thead><tr><th scope="col">Key</th><th scope="col">Action</th></tr></thead><tbody><tr><td>Tab</td><td>Moves into the selected tab, then into the tab panel</td></tr><tr><td>Arrow Right / Left</td><td>Moves to and activates the next / previous tab, wrapping</td></tr><tr><td>Home / End</td><td>Activates the first / last tab</td></tr></tbody></table>

## Screen reader notes
Announced as "tab, selected, n of m" within a labelled tab list. The panel is labelled by its tab and is focusable (tabindex 0) so keyboard users can reach non-interactive panel content.

## Known limitations
<ul><li>Automatic activation (focus selects) was chosen because panels are static. For panels that load data, manual activation would be better.</li><li>No vertical orientation support.</li></ul>
